系统公告与协议
v2.1.0 更新 最新
1. 专属壁纸双模存储：支持为单聊设置独立背景壁纸，并新增「全局聊天页面统一 / 单独保存在此聊天」一键切换。
2. 新增【功能区】：上线「异地恋模式」，可自定义双方所在英文地名与别称，AI 自动感知两地时差、真实天气、节日与牵挂氛围。
3. 新增【提示词】：开放自定义系统提示词，支持关闭内置法则，API 严格执行专属提示词规则。
4. 聊天专属头像重构：彻底修复头像设置后气泡不生效问题，支持点击即时同步与全局数据安全持久化。
5. 纯净极简灰白：全面优化 iOS 液体微光毛玻璃质感，移除所有 Emoji，全量采用高精度 SVG 矢量图标。
v1.3.0 深度体验优化更新 历史
1. Message 体验升级：创建账号改为原生全屏页面；列表好友改为长按弹出置顶/免打扰/删除；新增消息应用独立全局壁纸。
2. 聊天专属头像修复：修复了在聊天设置中上传专属头像后聊天气泡不显示的重大问题。
3. 世界书与联系人打通：支持在创建/编辑角色时直接关联世界书，关键词移至条目下方规范排版。
4. 透明底图与主题支持：上传组件及图标支持 PNG 透明背景；清空主题将同步清空所有小组件图片。
v1.2.0 系统架构与记忆库发布 历史
1. 新增双 API 架构与 MiniMax 官方直连。
2. 新增长期记忆总结系统与真实环境时间感知。
3. 引入全机数据导出与导入恢复中心。

更新公告
v 2.1.0
更新时间：2026年9月20日
一、Message模块优化
1. 新增聊天专属壁纸功能，仅在角色聊天页面生效，新增操作按钮，支持选择全局聊天页面统一应用壁纸或是单独保存至当前聊天。
2. 新增功能区分区，内置异地恋模式胶囊滑动开关，开启后向下展开填写面板，需要填写用户所在地（地点英文+别称）、角色所在地（地点英文+别称），点击保存后角色将识别异地恋状态，读取对应异地恋时间天气节日相关信息。
3. 新增提示词分区，支持用户自定义填写提示词，需关闭内置提示词开关后，API才会读取用户自定义提示词内容。
4. 修复角色专属头像显示异常问题，完成头像设置后可在聊天页面头像框正常展示，下滑页面点击保存设置，即可保存全部配置内容，包含专属头像并同步应用至聊天页面。
二、Message应用优化
1. 创建账号调整为全屏展示，不再使用弹窗形式。
2. 联系人列表操作调整，置顶删除免消息打扰功能修改为长按唤起，取消左滑操作。
3. 优化我的页面，新增消息壁纸设置项，壁纸为APP全局背景，全屏覆盖包含顶栏，不会对聊天壁纸产生影响。
4. 修复聊天头像BUG，解决上传定制专属头像后聊天页面无法正常显示的问题。
三、联系人世界书APP优化
1. 支持在填写联系人信息时绑定已创建完成的世界书。
2. 酒馆导入卡片对应的世界书，将关键词放置在世界书条目名称下方。
四、主题APP优化
1. 点击全局清除功能同步清除小组件图片，切换预设主题同步切换小组件图片。
2. 上传图片功能支持透明底图片，小组件同样支持上传透明底图片。
五、输入文字修改优化
1. 应用名称设置为固定内容，禁止点击修改。
六、数据优化
1. 所有功能更新均保留全部用户数据，包含聊天记录、导入或创建的角色卡数据、世界书数据，不执行强制清除操作，用户所有设置内容全部持久保存。
七、公告APP新增
1. 新增更新公告板块，所有版本更新记录在此存储，按照新更新在前旧更新在后的顺序排列。
八、BUG修复与体验优化
1. 修复Message用户头像保存失效问题，退出APP重新进入后头像数据不会丢失。
2. 优化char引用user消息逻辑，不再整段引用文本，支持单条消息气泡引用回复，保障格式不会错乱。
3. 优化转账消息逻辑，不再固定将转账内容放在第一句，支持自然对话行文，在对话过程中提及转账时再输出转账内容，后续可继续接续对话内容。
